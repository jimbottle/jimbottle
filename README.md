# Evan Ray

Data and analytics engineer, and the person behind [Raylytics](https://raylytics.io).
I build data pipelines, dashboards and reporting for clients, and in between I ship
small tools and apps that scratch my own itches.

Most of my day-to-day work lives in private client repos, so the contribution graph
tells more of the story than the public repo list.

## Things I've built

| Project | What it is |
| --- | --- |
| [Lou](https://github.com/jimbottle/louisville-open-data-expenditure-bot) | An agentic analytics assistant over Louisville Metro open data. Plain-English questions become verified SQL over 2.26M expenditure rows, with charts and citations. [Try it](https://louisville.raylytics.io). |
| [would-you-kindly](https://github.com/jimbottle/would-you-kindly) | A Go terminal UI over the beads issue tracker, built for agent-to-human handoffs. Installs with Homebrew. |
| [Just My Weather](https://github.com/jimbottle/just-my-weather) | A Kotlin Android weather app that shows only what you choose, with rule-based personal alerts. [On Google Play](https://play.google.com/store/apps/details?id=io.raylytics.justmyweather). |
| [Custom Color Palette](https://github.com/jimbottle/workspace-custom-palette-public) | A Chrome extension that puts your brand colors in the native Google Docs, Sheets and Slides color pickers, with a synthetic monitor that catches Google DOM changes. |
| [ir-sniffer-blaster](https://github.com/jimbottle/ir-sniffer-blaster) | An ESPHome ESP32 board that learns infrared remote codes and replays them through Home Assistant. |
